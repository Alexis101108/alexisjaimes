# DIGITAL CIRCUIT LAB

Simulador educativo inicial de compuertas lógicas.

## Uso local
Abre `index.html` en un navegador moderno.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra a Settings > Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la dirección de tu página.

## Funciones
- Entradas 0/1 y salidas LED.
- Compuertas AND, OR, NOT, NAND, NOR, XOR y XNOR.
- Conexión de pines con clic.
- Movimiento de componentes.
- Simulación básica en tiempo real.

Es una versión inicial: las conexiones sin cable se interpretan como 0 y el simulador está pensado para circuitos combinacionales sencillos.


La interfaz utiliza símbolos gráficos de compuertas (no solo etiquetas de texto), entradas 0/1, pines y un indicador LED visual.
